# Portfolio GitHub Personal

## Cấu trúc thư mục

- index.html: file HTML chính chứa toàn bộ sections về About, Projects, Certificates, Contact.
- assets/css/styles.css: CSS tùy chỉnh cho active state, dark mode và filter.
- assets/js/main.js: JavaScript cho smooth scroll, mobile menu, dark mode và certificate filter.
- assets/images/: chứa ảnh minh họa cho các project.
- assets/cv.pdf: file CV mẫu dùng cho nút Download CV.
- assets/certificates/: chứa các file PDF chứng chỉ mẫu.

## Cách chỉnh sửa

1. Mở index.html và thay tên, mô tả, links GitHub, email, social links.
2. Thay file CV tại assets/cv.pdf.
3. Thay ảnh project ở assets/images/project1.svg và assets/images/project2.svg.
4. Thay file PDF chứng chỉ trong assets/certificates/.
